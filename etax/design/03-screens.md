# 03 · 页面与交互

每页写：布局（从上到下）、交互规则、状态、对应代码。组件编号见 [02-components.md](02-components.md)。可视化样稿见设计画布（`mockups/` 有源文件，内联样式即数值）。

## S0 · 整体结构

```
首页（对话）
 ├─ 左：会话侧栏 ── 搜索 / 工作区快捷入口 / 会话列表 / 设置 · 权限
 ├─ 中：模型胶囊 ── 对话设置面板（模型 / 自动朗读 / 压缩 / 导出）
 ├─ 右：新对话、任务中心
 └─ 底：实时任务条 → 任务预览窗；排队条；输入栏

任务中心（新）── 进行中 / 已完成 / 常用任务
设置（重新分组）── 系统就绪卡 + 8 个分组 → 现有二级页面

系统级浮层（不在 App 内）：电源键助手面板、顶部状态胶囊、任务预览窗、任务通知
```

## S1 · 首页（对话）

### S1.1 顶栏
`≡`（打开侧栏）· 模型胶囊（居中）· 新对话 · 任务中心（有运行中任务时右上角 16dp 角标显示数量，底 `accent`）。
- 角色对话：模型胶囊左侧改为角色头像 24 + 角色名，点头像进角色详情（沿用现有 `CharacterTopBarIdentity`），模型胶囊收为仅图标。

### S1.2 空状态（新对话）
从上到下（内容整体在可视区上 1/3 处开始）：
1. η 标志：48dp，流光渐变字形（静止，进入时 aurora 平移一次 600ms）。
2. 问候 `display`：按时间「早上好 / 下午好 / 晚上好」。
3. 副标题 `subhead textSecondary`：「说一句，我在前台或后台帮你做完。」
4. 建议卡 2 列网格（间距 12），最多 4 张：
   - 前两张来自**常用任务**（最近使用优先）：图标块 `tileIndigo` + 名称 `rowTitle` + 指令前 1 行 `footnote`；点按 = 直接执行（与常用任务页「运行」相同，开新会话）。
   - 其余为示例（没有常用任务时 4 张都是示例）：「在后台帮我点一杯咖啡」「总结今天的未读通知」「打开设置检查电池健康」「搜索并比较两款手机」。点按 = **填入输入框**，光标在末尾，不自动发送。
   - 卡片：底 `surface`，圆角 `radiusMd`，内边距 14，高 88；按压缩放 0.98。
5. 首次安装且「系统就绪」有缺项时，建议卡上方显示一条 `attention` 提示卡：「还差 2 项设置才能在后台操作 App」+「去完成」→ 设置页就绪卡。

### S1.3 对话中
- 消息列：最大宽度 720 居中；消息间距：同一轮内 12，轮与轮之间 24。
- 用户消息 C20；助手消息 C21；工作过程 C22 放在该轮助手正文之前。
- 输入栏 C24 固定在底部；其上依次是排队条 C25、实时任务条 C23；回到底部按钮 C26。
- 首次打开长会话：直接定位到底部，无滚动动画；向上滚到顶部自动加载更早消息（沿用现有分页），加载时顶部显示骨架行。
- 流式中：底部跟随（沿用现有 `resolveBottomFollowDecision`），用户手动上滑后停止跟随并出现回到底部按钮。

### S1.4 对话设置面板（点模型胶囊）
EtaSheet，标题「对话设置」：
1. **模型**：按服务商分组的列表（服务商小标题 `caption`），每行：模型名 `rowTitle` + 能力小标签（视觉 / 思考 / 工具，`caption` 灰底 Chip）+ 选中对勾 `accent`。顶部搜索框（模型 > 8 个时出现）。底部「管理模型服务商 ›」→ 模型服务商页。
2. **本对话**（分组列表）：自动朗读（开关，仅配置了语音合成时显示）、压缩上下文（按钮行，显示当前 token 占用，不可用时禁用并说明）、导出对话（Markdown）。
- 选模型后面板自动关闭，Toast「已切换到 xxx」。

### S1.5 附件面板（点 `+`）
EtaSheet 菜单型，4 个大图标格（2×2 或横排 4 个）：图片、文件、文件夹、设备路径。下方可选「最近图片」横向缩略图（若读取相册已授权；否则不显示，不主动申请权限）。

### S1.6 消息长按
- 用户消息：复制 / 编辑 / 删除。
- 助手消息：复制 / 朗读 / 重新生成 / 删除。
- 删除需确认（EtaDialog，Destructive）。

### S1.7 实时任务条交互
见 C23。补充：
- 任务完成：条变为 `success` 状态 3s「已完成 · 用时 2分13秒」，然后收起（`medium`）；结果正文正常进入对话。
- 任务失败/停止：条变 `danger`，保留到用户点 ×。
- 用户在预览窗接管后返回 App：条显示「已暂停 · 你正在操作」，按钮变「交还 AI」。

### S1.8 横屏与平板（≥840dp）
侧栏常驻左侧（宽 320，`surface`，右侧 1px `outline`），对话区居中最大 720；任务中心在对话区右侧以 360 宽面板打开（不跳页）。

## S2 · 会话侧栏

保持现有「推移」式侧栏（`ConversationSidePaneScaffold`，主内容随之右移并缩小圆角），宽度 min(84%, 360)，底 `surface`。
1. **顶部**（距状态栏 8）：搜索框 C9 + 右侧「新对话」图标按钮。
2. **工作区快捷入口**：一行 4 个，等宽，每个 = 图标块 40（分类色）+ `caption` 名称：任务（`tileIndigo`，有运行时右上角角标）、角色（`tilePink`）、终端（`tileSlate`）、浏览器（`tileTeal`）。Kimi Code 以第 5 个出现（若已配置），横向可滑。
3. **会话列表**：分组小标题（置顶 / 今天 / 昨天 / 7 天内 / 更早，`caption textTertiary`）。
   - 行高 48，左右内边距 12，圆角 `radiusMd`；标题 `rowTitle` 15sp 单行；右侧相对时间 `caption textTertiary`。
   - 当前会话：底 `accentSoft`，标题 `onAccentSoft`。
   - 有任务在跑的会话：标题左侧 `StatusRing 12`（运行中/需要你）。
   - 长按：触感 + EtaSheet「重命名 / 导出 / 删除」（删除二次确认）。
   - 搜索中：列表实时过滤，匹配字高亮 `accent`；无结果显示 C14 空状态。
4. **底部固定栏**（顶 1px `outline`，高 64）：左「设置」（图标 + 文字；系统就绪有缺项时图标右上角 `attention` 圆点）；右「权限」（图标 + 「1 项待处理」或「全部正常」，`subhead`）。

## S3 · 任务中心（新增路由 `AppRoute.Tasks`）

大标题顶栏「任务」，下方分段控件 C10：**进行中 · 已完成 · 常用**。默认：有进行中任务时选「进行中」，否则「常用」。

### S3.1 进行中
每个运行中/暂停/需要你的任务一张卡（EtaCard，内边距 16）：
```
[应用图标 24] 美团 · 点外卖                [状态 Chip]
┌────────┐  正在点击“提交订单”
│ 实时   │  第 8 步 · 1分12秒
│ 缩略图 │
│ 72×156 │  [查看]  [暂停]  [停止]
└────────┘
```
- 缩略图：圆角 `radiusSm`，1px `outline`；仅当本页可见且卡片在屏幕内时，每 2 秒取一帧（复用 `preview_frame` RPC，`edge` = 320）；离开页面立即停止。无画面时显示应用图标居中的占位。
- 「查看」(Tonal) → 任务预览窗；「暂停/继续」(Secondary)；「停止」(Destructive Small) → 确认对话框。
- 前台任务（不在虚拟屏）不显示缩略图，卡片只有文字。
- 「需要你」的卡片排在最前，用状态 Chip + 卡片 1.5dp `attention` 描边标出（不用左侧色条）。
- 空：C14「没有正在执行的任务」+ Tonal「从常用任务开始」→ 切到「常用」页签。

### S3.2 已完成
最近 20 条（来自通知卡片 / 运行归档，按结束时间倒序）：行 = StatusRing 16 + 标题 `rowTitle` + 副行「美团 · 14:32 · 用时 2分13秒」`footnote textTertiary` + 尾部「打开 App」Small Secondary（目标应用可打开时）。点行 → 打开对应会话。

### S3.3 常用
现有 `CommonTasksScreen` 的内容换装：
- 每条一张卡：名称 `headline`、指令前两行 `subhead textSecondary`、底部「运行」Tonal Small + 右侧「…」（编辑 / 复制 / 添加到桌面 / 删除）。
- 右下角扩展悬浮按钮「新建」（Primary，高 52，圆角 full，`e2`），列表滚动时收为圆形。
- 编辑页：名称输入、指令多行输入（`body`），底部 Primary「保存」。

数据：进行中 = `AgentExecutionService` 卡片快照（同进程，新增 `StateFlow`）+ `TaskPreviewRegistry`；已完成 = 同一快照中 `completed` 的卡片 + 归档；常用 = 现有 `CommonTasksStore`。

## S5 · 任务预览 / 接管窗（`TaskPreviewActivity`）

**这是最需要重做的界面**（现在是安卓原始 `Button` 拼的）。浮在屏幕上方的卡片，不占全屏。

### 布局
```
╭──────────────────────────────╮  ← surfaceRaised(深色强制) 圆角 28, e3
│ [App 图标 24] 美团   [状态Chip] [⤢][✕] │  ← 头部 52
│ ╭──────────────────────────╮ │
│ │                          │ │
│ │      实时画面            │ │  ← 圆角 16, 1px 描边
│ │   （接管时显示触点波纹）  │ │
│ │                          │ │
│ ╰──────────────────────────╯ │
│ 正在点击“提交订单”             │  ← 提示行 footnote, 单行
│ [   主按钮   ] [次] [次]       │  ← 操作栏 48
╰──────────────────────────────╯
```
- 窗口固定深色（不论系统主题），因为画面是另一个 App，深色边框不抢画面：底 `#16171C`，文字 `#ECEDF2`，描边 `#2A2C35`。
- 小窗宽 = 屏宽 × 0.62；放大后宽 = 屏宽 − 32。切换用 `long` 弹簧，画面区等比缩放（沿用现有 `resize` 逻辑，只换动画曲线）。
- 头部按钮均为 Icon 按钮（放大/缩小 `OpenInFull`/`CloseFullscreen`，关闭 `Close`），不再是文字按钮。
- 进入：从顶部下移 16dp + 淡入 `long`；关闭：上移淡出 `short`。

### 操作栏状态机
| 状态 | 状态 Chip | 主按钮 (Primary) | 次按钮 | 提示行 |
| --- | --- | --- | --- | --- |
| AI 执行中（观看） | 运行中 | 接管 | 暂停 | 当前步骤 |
| 已暂停 | 已暂停 | 继续 | 接管 | 「任务已暂停」 |
| 接管中（你在操作） | 已暂停 · 你在操作 | 交还 AI | 返回键（`ArrowBack` 图标按钮）、主页键* | 「点击画面即可操作」/ 上次输入失败原因 |
| 需要你 | 需要你 | 接管处理 | 暂停 | 「需要你输入验证码」 |
| 正在交接（等待操作结束） | 运行中 | 按钮显示转圈「等待当前操作结束…」，禁用 | — | 同左 |
| 已完成 | 已完成 | 打开 App | 关闭 | 结果一句话 |
| 失败 / 画面不可用 | 未完成 | 关闭 | 打开会话 | 错误原因 |

\* 主页键仅当引擎已支持对应 `key` 输入时显示；不支持则不显示，不新增引擎能力。

- 接管时：画面外框变为 2dp `accent` 描边；每次点击在触点画 `accent` 30% 的扩散圆（沿用现有本地波纹），滑动画跟随轨迹。
- 输入失败：提示行变 `danger` 色，保留到下一次操作（沿用现有 `inputFeedback` 规则）。

### 实现要求
- `TaskPreviewActivity` 已是 `ComponentActivity`：改为 `setContent { EtaPreviewWindow(...) }`，画面区用 `AndroidView` 承载现有 `TaskPreviewImageView`（触摸、手势、几何换算逻辑**一行不改**）。
- 保留窗口属性：`FLAG_SECURE`、`FLAG_NOT_FOCUSABLE`、顶部重力与 `y` 偏移、`dimAmount`。
- 轮询、`rpc`、`acquire/release`、`invalidateFrame`、`postInputFrameUntil` 等逻辑不动；只把 `status/hint/take/resume/back/zoom/openApp` 这些 View 的读写改为 Compose 状态。
- 现有 `TaskPreviewActivityTest` 通过反射读取 `picture`、`hint` 字段：改造时同步更新测试为读取新的状态对象，覆盖上表每个状态的按钮文案与可用性。

## S8 · 任务通知（`AgentExecutionService`）

通知外观受系统限制，只统一**文案结构、图标、颜色、按钮**：
- `setColor(accent)`；小图标沿用 `ic_notification`。
- 标题：「{应用名} · {任务名}」（无应用时只有任务名），最长 60 字。
- 正文模板：
  - 运行中：「正在{动作} · 第 {n} 步」
  - 需要你：「需要你{做什么}」（如「需要你输入验证码」）
  - 已暂停：「已暂停 · {原因}」
  - 完成：「已完成 · 用时 {时长}」+ 结果首句
  - 失败：「未完成 · {原因}」
- 按钮（最多 3 个，顺序固定）：运行中「查看 · 暂停 · 停止」；暂停「查看 · 继续 · 停止」；完成「打开会话 · 打开 App · 继续指令」（保持现有三个完成按钮）。
- 支持的系统继续使用 Live Updates / 流体云（现有逻辑不动），进度用步数。
- 「回复失败」等附加提示接在状态词后：「已完成 · 回复未发送」。

## S9 · 首次使用与权限页

- 权限页（`PermissionHealthScreen`）：顶部就绪卡（同 S4.1 放大版），下面每项一张卡：图标块 + 名称 + 状态 Chip + 一句话说明 + 操作按钮（「去开启」Tonal / 「已开启」无按钮）。按「需要你」优先排序。
- 首次打开 App（无任何会话、就绪有缺项）：空状态上方的提示卡引导到这里（S1.2 第 5 点），不做多页引导轮播。
