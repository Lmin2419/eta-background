## 分期

1. **稳（2026111414）**：真机模式截图测试接进 CI；深色、200% 字体、宽屏检查；重复信息排查。
2. **统一**：Miuix 残留换 COUI；侧栏用上游 COUI 原生搜索栏；「已完成 · N 步」变轻；电脑会话页顶部玻璃控件。
3. **好用**：「复核报错再试」；改文件返回改动行；回复时切模型下一轮生效；别的对话完成时的提示条。
4. **打磨**：渲染诊断与采样源精简；新对话空白页重排；侧栏手势与横向滚动。

## 规则

- **一个信息只在一个地方出现**：标题和模型在顶部；运行状态在对话流里；别的对话的后台任务在胶囊；完成提醒在应用外用通知（正在看的对话不弹横幅）。下拉行的副标题如果就是当前值，不再显示。
- **修问题先复现**：本机复现（截图对得上），改完用同一个测试证明，再出包。
- **真机模式截图**：`DeviceModeScreens`（`EtaCouiSupport.shaders = true` + 硬件渲染 PixelCopy）。首页、侧栏、宽屏走真机布局；设置类页面的 COUI 顶栏着色器（`layout(color)`）本机编译不了，截图时走测试骨架，页面内容（行、开关、卡片）仍是真机那套。截图时关掉模糊（本机编译不了 Miuix 模糊着色器），所以截图看布局、深色、字号，不看玻璃本身。
