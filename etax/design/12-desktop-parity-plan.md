# 12 号方案：电脑会话功能对齐（2026111625 之后）

用户反馈「电脑端功能太少，再对齐一些」。对照两边：

- **手机自己的对话**已有、但在电脑会话里被关掉的功能（界面现成，只差接到 DSH）；
- **DSH 桌面版**有、但插件（dsh-bridge 0.5.0）还没转到手机的能力（对照 `deepseek-harness` 0.2.2 源码）。

## 0. 现状

插件已转发：会话列表/搜索/新建/重命名/归档/置顶、发送（排队/插队、图片、文件）、取消、队列编辑、跟随与翻页、子代理（查看、发消息、中断）、模型与思考强度、审批、提问与计划审阅、完成提醒、统计/用量/上下文压力投影。

## 1. 差距

### 1.1 手机界面现成、电脑会话关掉的

| 功能 | 现在 | DSH 能力 | 做法 |
| --- | --- | --- | --- |
| 压缩上下文 | `canCompactContext = false` | `/compact` 命令（`commands.execute`） | 插件转发命令执行；按钮直接发 `/compact` |
| 从这里分支 | `onBranchMessage = {}` | `sessionController.fork({sessionId, atSeq})` | 新增 `sessions.fork`；长按消息「从这里分支」→ 打开新会话 |
| 改写后重发 | 只把原文放回输入框，当新消息发 | fork 到这条用户消息之前 + 发送改后的文字 | 「改写」默认在分支里重发，原会话不动 |
| 重新生成 | 提示「不支持」 | `prompt` 空内容 = retry（最后一轮）；更早的轮次用 fork + retry | 最后一轮原地重试，更早的在分支里重试 |
| 上下文用量环 | 电脑会话不显示 | `pressure` 投影已在转发 | 用 `pressureTokens / contextWindow` 显示 |
| 引用电脑上的文件 / 文件夹 | 提示「不支持」 | `fileReferences.list(agent, query)`（`@` 补全） | 新增 `files.complete`；附件菜单「电脑上的文件」→ 搜索选择 → 以 `@路径` 写进消息 |
| 删除单条消息 | 提示「不支持」 | 无（DSH 历史只追加） | 不做 |

### 1.2 DSH 有、手机还没有的

| 功能 | DSH 能力 | 做法 |
| --- | --- | --- |
| 斜杠命令 | `commands.list(agent)` / `execute(agent, line)`：`/compact`、`/goal`、`/plan`、`/permission`、`/export`、`/feedback`，加上可直接调用的技能 | 输入 `/` 弹出电脑上可用的命令（名称、说明、参数提示），选中执行 |
| 权限预设、计划模式 | `/permission`（只读 / 工作区可写 / 完全访问…）、`/plan` | 会话标题胶囊里显示当前预设和是否在计划模式，可切换 |
| 新建会话选预设 | `sessions.create` 已支持 `agentPreset` | 新建时可选工作区和 Agent 预设（预设列表需插件转发） |
| 后台任务 | `job`：`list`、`follow`（看输出）、`kill` | 会话里「后台任务」入口：列表、实时输出、停止 |
| 改动的文件 | `workspace-files`：`list`、`read`、`changes` | 本会话改过的文件列表，点开看内容（先不做逐行 diff） |
| 目标 / 待办 | `/goal`、`todo_write` 工具结果 | 会话顶部显示当前目标和待办清单 |
| 导出会话 | `/export` | 导出的 Markdown 发到手机，可分享 |
| 终端 | `terminal` 命名空间（交互式） | 暂不做（手机上交互价值低、实现重），后台任务输出先覆盖「看结果」 |

## 2. 分期

每期一个手机版本 + 一个插件版本（电脑上 `git pull` 后重启 DSH 桌面版生效）。手机按插件 `hello.features` 判断能力，旧插件不显示新入口。

| 期 | 内容 | 插件 |
| --- | --- | --- |
| 一 · 把关掉的打开 | 压缩上下文、从这里分支、改写后重发（分支）、重新生成（重试 / 分支重试）、上下文用量环、引用电脑上的文件 | 0.6.0：`sessions.fork`、`commands.execute`（先只放 `/compact`）、`files.complete`、`sessions.retry` |
| 二 · 斜杠命令 | 输入 `/` 弹命令和技能；权限预设、计划模式显示与切换；新建会话选预设 | 0.7.0：`commands.list`、`commands.execute`（全部）、`presets.list` |
| 三 · 看得见电脑在干什么 | 后台任务（列表、输出、停止）、改动的文件、目标与待办、导出会话 | 0.8.0：`jobs.*`、`files.changed` / `files.read`、`sessions.export` |

## 3. 守则

- 不改 DSH 本身，只用它已公开的服务；DSH 缺某个服务时插件返回 `unavailable`，手机隐藏入口。
- 会改变电脑状态的操作（分支、命令、停止后台任务、切换权限）照常走 DSH 自己的审批与校验；完全访问权限切换在手机上二次确认。
- 每期：插件单测 + 真 DSH（0.2.2）联调；手机单测、lint；CI 全量通过再出包。
