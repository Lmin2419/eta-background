## 动效、无障碍与性能

自有短动画采用 100 / 180 / 260 / 380ms 和 standard / emphasized-decelerate；自有退出取进入的 70% 并使用 accelerate；可拖面板回弹使用 `.86 / 420`。`EtaAnimatedVisibility`、`EtaAnimatedContent`、`EtaCrossfade` 在减少动画时覆盖调用方的空间变换，取消 SizeTransform；分段/箭头/列表位移直接结束。手指主动拖动仍跟手，不因无障碍设置禁用交互。库宿主动效见 D3。

`Settings.Global.ANIMATOR_DURATION_SCALE` 变化由 observer 监听；值为 0 时应用动效 token ≤120ms，Compose/平台自身通常直接结束动画。助手/边缘流光、状态环、打字指示和工作过程的循环在减少动画时停下；`SmoothTextReveal` 保持原揭示机制。屏幕边缘流光在 draw 读取旋转状态，避免逐帧重组。

静态检查覆盖 64 个 IconButton 调用，并核对预览、输入、任务、胶囊、助手的自绘动作语义。浏览器刷新图标的 null 描述有父节点完整描述，不重复朗读。任务摘要合并边界使用 `clearAndSetSemantics`，按钮继续独立可聚焦；新增“后台执行中”同步简中、繁中、英文。

| 对比度组合 | 最低实测比值 | 门槛 |
| --- | ---: | ---: |
| 浅色三级文字 / canvas、surface、sunken | 4.56:1 | 4.5:1 |
| 深色三级文字 / canvas、surface、raised、sunken | 4.62:1 | 4.5:1 |
| 浅色 warning / success / error 文字与对应 Soft 底 | 4.69:1 | 4.5:1 |
| 深色状态实底与深墨符号 | 7.16:1 | 3:1 |

`EtaContrastTest` 另检查主/次文字、默认 accent/onAccent、onAccentSoft 和 Toast；不声称用户任意自选色、Monet 动态色或网页内容全都达到同一比值。

宽屏沿用阶段 3 的 ≥840dp 常驻 320dp 侧栏、右侧 360dp 任务面板。1280dp / 840dp 自动化保留，新增 900×411dp 深色横屏回归。500 条消息、90 帧滚动样本中可见 item 上限 9；本次 native CPU render proxy 中位 7.04ms、P95 13.06ms，保留惰性列表和 draw-phase 动画，不作为真机 FPS 声明。
