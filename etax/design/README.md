# Eta 后台版 UI 改版设计

设计名「静流」：**界面安静，AI 在动。** 中性底色 + 一个品牌蓝（Eta 蓝 `#4B5BFF`）；只有 AI 正在工作的地方才出现流光渐变和动效。全 App（对话、侧栏、设置、二级页）与系统级浮层（任务预览窗、电源键助手面板、顶部胶囊、通知）共用一套语言和一张状态表。

## 给 Codex

按 `04-implementation-plan.md` 从阶段 1 开始，**一个阶段一次提交、一次发版**。数值以 `01` 为准；画布与文档不一致时，以文档为准并在版本说明里指出。

## 主要变化一览

- 顶栏中间换成模型胶囊，模型、自动朗读、压缩上下文、导出集中到「对话设置」面板；输入栏只保留输入、附件、思考强度、语音/发送。
- 新增**任务中心**（进行中 / 已完成 / 常用），对话内新增**实时任务条**：后台任务不必再从通知里找。
- 设置从一条长列表改为「系统就绪卡 + 8 个分组」，所有设置项保留。
- 任务预览/接管窗从安卓原始按钮重做为深色浮窗，按状态切换主按钮（接管 / 继续 / 交还 AI / 打开 App）。
- 五种任务状态（运行中、需要你、已暂停、已完成、失败）全局统一颜色、图形和文案。
