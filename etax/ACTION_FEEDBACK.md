# 通用操作反馈（开发中，未发布）

基线：55c3eed287bbe5b5c7fed60e2c46ace1947d7f9c。用户报告“点击添加设备后提示约两秒消失，模型没看到，反复点了多次”；本次实现通用行为，不推断具体激活码、账号或网络故障。

## 执行过程

1. 保留原操作权、观察、几何和权限检查。在动作前打开仅属于本次任务/包名/显示屏的反馈窗口。
2. 无障碍回调复制少量文字，不在回调线程读节点或截图。不把另一个任务的 Toast、过期事件或普通通知当成本次结果。缺少显示屏信息时，由有界后台队列核对窗口；有歧义则不归属。
3. 可能产生短反馈的操作，在约 150/500/950ms 尝试读取画面。前台复用无障碍窗口截图及原遮罩规则；后台复用认证后的 `preview_frame` 内存传输，不取得手动租约、不修改 AI 观察帧。慢截图、受保护窗口或页面已移走时允许无图。
4. 同次工具结果的 `action_feedback.texts` 返回文字、来源和相对时间。没有文字反馈且没有可验证节点变化时附历史图片；通过现有模型图片附件投递，内部 base64 从工具文字中移除。没有新增 OCR 服务或模型请求。
5. `ok/accepted`、节点变化、业务成功仍是不同事实。短提示可能来自异步界面活动，不能仅凭相关时间证明因果；反馈内容是应用数据，不是 Agent 的指令。原 `ACTION_OUTCOME_UNKNOWN`、几何失败与 `operationMayHaveRun` 不被反馈升级成成功。
6. 模型必须结合提示、输入值与最终结果决定下一步。对可识别的相同目标，重复两次仍无确认则返回 `NO_PROGRESS`、本次不输入；更换点击 API、重新观察同一状态不重置预算。真实界面状态变化、独立任务和新绑定不共享预算。

## 开销和隔离

- 最多三个活动反馈窗口；每个最多八条、每条 512 字符，优先保留 Toast/公告；最多保留五秒的收集窗口，无持续文字数据库。
- 两个抓帧线程、有界队列；每次最多三次尝试、两张不同图片，每张 base64 不超过 300,000 字符。保留最早及最后不同画面；相同 JPEG 不重复附图。
- 节点变化或已取得文字反馈时无需等待剩余抓帧；结果不明时仅等待操作开始后约 1.15 秒，不另外固定等待几秒。已有工具本身的调用/超时时间不在这个上限内。已在系统调用中的截图可能晚到，结束后丢弃，不能保证强行中止 Binder。
- 文字反馈标记为敏感工具结果，不写入原始工具历史；图片沿用模型已有附件处理。线程不写录屏文件或运行截图目录。
- 前后台仍由现有 Runtime/单个 VDrive 管理；没有第二个引擎、全局“当前屏”、跨屏回退或修改系统动画。一个任务的捕获失败不阻止另一个任务。

## 输入与键盘

前台 `replace_text/type_text` 在等待控件稳定后，从新根节点定位原输入框，核验真实内容（不把 hint 当内容）；身份变化或内容不一致则返回 `ACTION_OUTCOME_UNKNOWN`。后台 `screen_text` 等待稳定回读，不增加抢焦点操作；密码内容不回显。节点内容一致仅代表节点层核验，不证明应用已经提交业务数据。

节点观察的 `keyboard.known/visible` 指当前对应显示屏。只有截图、无节点/窗口证据时可能是未知；BACK 仍是返回键，不改成未经确认的“收键盘”。

## 手机验证（尚未执行）

- 一个会短暂弹出校验提示的普通页面：点击一次，核对同次工具结果是否包含提示原文或对应反馈图片；不能把预期写成实际。
- Flutter/自绘提示：核对图片是否覆盖短提示。原始截图未提供文字时，不声称已读出提示；未知提示继续明确未知。
- 提交目标连续不变：重复两次后改用节点/坐标/长按，确认返回 `NO_PROGRESS` 且没有第三次输入；修改实际输入值后允许继续。计算器连续有效按键不应被误阻止。
- 两个不同 App 后台并行：各自产生提示，仅各自任务可收到。将一个 App 移到主屏或取消任务时不沿用旧截图坐标。
- 输入框拒绝或撤销写入：不能仍报告 `verified=true`；未确认输入时不能自动提交。前台键盘正常使用时，后台写入不得抢掉键盘。
- 接管/恢复、旧 `screen_*`、流体云与每任务通知沿用原回归；本次不触发长按电源键软重启复现，不宣称历史软重启已修复。

## 限制

这能覆盖跨 App 的短反馈问题，但不是每条提示必达：ROM 可能不提供可访问文本，安全窗口禁止截图，画面可能短于采样间隔，截图服务可能限速，模型也可能无法辨认图片。无法拿到证据时保留未知，不以“没有截到”推断“没有出现”。纯视觉目标没有可靠身份时，自动跨 API 重试合并不会猜测目标；模型仍须遵守不盲目重放的通用规则。
