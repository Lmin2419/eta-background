## 2. 实际完成的四项

### 统一任务状态

复用 AgentRuntimeSession.complete/cancel 的终态裁定，TaskPresentation 只投影已有结果、RuntimeRunRegistry 阶段及暂停原因，未建立第二套任务数据库。通知、运行界面与预览显示排队、准备、等待 GUI、暂停、停止中、收尾和实际终态；模型停止流式输出不提前完成卡片。归档提交后更新原卡片，旧 ShadowNotice 完成回调不能提前覆盖 Runtime 权威状态。

完成/取消竞争、提交中状态、取消排队任务、暂停状态均有回归。全量回归发现并修复取消已暂停前台任务后恢复控件消失的问题：全局前台权限暂停继续保留恢复入口，不将任务终态与权限状态混为一套。

e45 空活动列表必撤运行彩边，旧前台历史仅供结果上下文；延迟显示回调不能重建已结束任务的彩边，已关闭完成卡片拒绝旧运行快照。一个任务完成不影响另一个实际工作的彩边。

### 通知作为三级预览入口

| 层级 | 实际行为 |
| --- | --- |
| 通知/流体云 | 仍使用 ProgressStyle；有后台目标 App 时请求小手机图标；位置和系统展开动画由 ROM 决定 |
| 点击通知 | 打开临时 App 小预览，只读，不暂停 AI，不移动原 App 到主屏 |
| 放大/缩小 | 只读可点画面放大；任何模式均有顶部独立缩放按钮；接管自动放大 |
| 关闭/隐藏 | 停止该窗口额外刷新并释放预览租约；不会取消任务或擅自恢复已暂停 AI |

Android Live Updates 不支持任意自定义通知画布。本候选按用户确认采用临时预览面板，不宣称实时画面嵌入原生流体云，不增加第二条卡片或常驻胶囊。通知内容点击与原“打开 App”action 使用不同 PendingIntent；运行/暂停卡片新增“打开 ETA 会话”独立按钮；三个完成入口“打开 ETA 会话 / 打开 App / 继续指令”和内联回复保留。

帧从现有 VDrive 的认证通道返回内存 JPEG，不调用会更新模型观察的 screen_shot，不持续写截图文件。小/大窗请求间隔约 800/350ms，长边最大 640/960px，编码上限 400KB，单窗口串行、缓存帧无变化跳过编码解码。隐藏停止消费者；已结束屏仅在查看时增加采集，关闭及空闲过期回收，活动任务原有采集保留。

通知图形改为可染色的透明镂空手机轮廓并缓存位图，防止不透明屏幕被统一染成白块；JPEG 质量提高为 78，超过原传输上限回退 65。小窗首帧前及纯黑白空画面显示不可操作的手机占位。触点圆环与滑动跟随只在本地绘制，最多 64 点，抬手淡出，不修改截图。窗口等比显示，按实际 ImageView 矩阵、内边距映射，横竖屏和黑边坐标有校验；旋转清理当前手势和旧几何。预览窗口不获取 IME 焦点，带 FLAG_SECURE，锁定时关闭。实际 ColorOS 焦点、主屏键盘及流体云布局仍待手机验证。

### 手动接管

控制绑定完整 runId 与包名，不使用全局当前屏或同包名兜底。每任务控制器暂停该任务，并等待已经准入的真实 transport 调用退出；引擎再检查 worker 排空及租约。等待或超时保持只读，不用第二条 root 输入路径抢跑。

e42 修复 idle/needs_observation 混淆导致的连续点击与完成页面接管失败：只放行已排空的人工操作，每次须本拥有者新预览，不清除 AI 观察保护。人工点按直接投到图像真实矩阵映射的目标像素，避免父节点虚假点击。另一个只读窗口不能释放正在人工控制的采集。

e43 修复任务仍保留 GUI 租约但暂停由预览直接施加时遗漏控制器恢复的问题；人工拥有者未释放不得虚报继续。三轮交还、另一任务隔离、真实只读/暂停提示均有回归。

取得控制后支持点按、长按、滑动和返回，旋转/几何变化拒绝旧坐标；超时或不确定结果不自动重放。另一任务继续执行。明确“让 AI 继续”时先释放手动控制再恢复任务，恢复代次让旧观察失效；单独关闭窗口不自动恢复。已结束任务只取得原保留页控制权，“结束接管”不复活旧 run；后续工作仍走通知内继续指令。

e44 修复主屏手动处理后，旧屏不可用阻断只读预览恢复的路径；手动租约释放仍检查拥有者与排空。Runtime 收尾及延迟预览关闭统一保留移屏采集至窗口就绪确认，同 App 交还中按 CLEANUP_PENDING 有界等待。输入错误不再被下一帧覆盖。验证码无响应未定因，ColorOS 闪烁改善须实测。

e45 最终回收在主屏就绪后直接释放虚拟显示，再关本地采集缓冲，减少先关输出再删屏的双重显示变化；释放失败保留资源供重试。实际 ROM 闪烁仍需验证。

手动租约 10 秒无请求过期。旧通知不能控制后来同 App 的任务；页面回收时明确不可用，不能为了显示预览重启 App。“打开 App”继续使用原交还确认。最近任务迁移时，旧 Surface 保留至主屏窗口就绪后释放；面板短淡入/淡出，交还桥禁用空白启动预览，不强制重启 App。ColorOS 的系统动画仍须实测。

### 息屏继续后台执行

参考上游独立显示组、OWN_FOCUS、STEAL_TOP_FOCUS_DISABLED 与 ALWAYS_UNLOCKED，保留本分支主屏输入法/焦点隔离。Runtime 不再在 SCREEN_OFF 暂停全部 run：后台任务、后台开屏过渡及纯分析可继续；前台已操作任务暂停，锁屏时前台工具拒绝执行。

用户手动暂停和接管暂停不因解锁自动恢复；不自动重放网络失败前可能已执行的动作。没有新增主屏亮屏锁、常驻保活服务、网络白名单修改或系统 Hook。上游本身没有证明可绕过所有 ROM 的深度休眠网络限制，本候选也不作此承诺。

## 2A. C011 三轮同步优化

### 第一轮：既有稳定性修复落入交付候选

保留 e45 通知会话按钮、最后一个任务完成后的彩边收尾、移出虚拟屏后的就绪确认与显示释放顺序。运行/暂停通知主体仍进入预览，独立按钮进入 ETA 会话，完成三个入口不变。复查没有发现足以支持额外改动引擎或系统 Hook 的证据，实际 ColorOS 过渡效果仍需手机确认。

本轮集成另修正界面关闭时只读恢复查询仍等待连接、以及常用任务快捷入口与新通知的导航竞争。取消只读查询不发送任务取消，不改变后台任务生命周期。

### 第二轮：执行效率与可测量耗时

- 普通读/复制/计数任务优先现有工具与界面；遇加密库、不可达路径和未知格式停止该探索分支，不无界写解析器或安装环境。明确开发/排障任务保留原能力。
- 固定统计起止时间，按真实重叠条目和上下文确认连续覆盖；同时间、同正文不能单独作为去重身份。动作结果不确定时重新观察，不盲目重放。
- 原生 observe_screen 已附图时无需再 read_image；旧 screen_* 保留。未见图不能因返回路径就自称已读图。
- 现有通知历史查询增加时间区间、稳定分页和留存匹配记录数；数据替换/过期时要求重查，不把通知条数当成完整聊天消息总数。不扩展原 7 天/1,000 条留存。
- 复用已有 Runtime 事件、归档和会话存储显示有界执行统计。阶段时间互斥，不添加模型请求、常驻服务或统计数据库；模型阶段含网络与服务端等待，不宣称是纯计算时间。取消/硬退出时统计可能不完整。

旧报告没有准确任务版本、当时模型或完整逐请求耗时，本次不估算提速比例。新方案说明与统计范围见 [源码文档](https://github.com/Lmin2419/eta-background/blob/55c3eed287bbe5b5c7fed60e2c46ace1947d7f9c/etax/EFFICIENCY_AND_COMMON_TASKS.md)。

### 第三轮：轻量常用任务

首页右上角菜单提供“常用任务”，本机保存名称和指令；支持创建、编辑、复制、删除、执行和桌面快捷入口。每次执行新建普通会话、使用当前模型，复用原队列与 Runtime，不继承旧历史/草稿/附件/角色；原通知“继续指令”仍继续原会话。

快捷入口按本机 ID 和随机校验值读取最新内容，已删条目不可执行，重复请求仅消费一次。没有定时、示范教学、跨会话项目或第二套执行器。任务目前未加入手动备份格式；桌面固定行为取决于 Launcher。

## 2B. C012 通用短反馈与结果核验

基于 C011 候选新增，最终源码为 `0ee03be47e482b8ae300584f5161e660f1f673cf`。前台、原生后台与旧 `screen_*` 共用操作前反馈监听；按任务、包名、显示屏和时间归属，不把别的任务提示拼进当前结果。

优先收集 Toast/公告等可读文字；缺文字且未确认节点变化时，最多三次内存采样尝试并附两张不同历史画面。反馈随同次工具结果交给模型，不额外请求 OCR/模型，不录视频或写持续截图文件。过时、无法归属或受保护的内容可以取不到，不能据此断言没有提示；图片不是下一次坐标合同。

可靠目标身份相同且状态未变时，两次提交后第三次返回 NO_PROGRESS、不输入。节点/坐标/长按共享预算，重新观察和失败收尾不能清空预算；有真实状态变化再允许继续。纯视觉目标身份不明时不猜测，继续保留模型侧不盲目重放规则。

输入待稳定后重新读取原节点，防止乐观回报后内容被撤回；hint 不是实际文本。后台不加抢焦点操作。观察增加本屏键盘状态，BACK 仍为导航，避免默认当成收键盘。截图-only 观察通过唯一主屏应用窗口定位反馈对象，不增加节点遍历。

这是通用接口改动，不是特定 App 适配，也不把动作投递或界面变化当成业务成功。资源上限与未覆盖情况见 [ACTION_FEEDBACK.md](https://github.com/Lmin2419/eta-background/blob/0ee03be47e482b8ae300584f5161e660f1f673cf/etax/ACTION_FEEDBACK.md)。没有新增常驻服务、数据库、系统 Hook 或第二个引擎。

## 2C. C013 坐标与完成页面交还

动作已提交后旧截图坐标失效，节点 after 仍可直接使用；有可靠主屏窗口信息时，触摸前检查 IME、窗口身份/边界和显示几何。静态页面不按时间过期。后台观察服务暂缺窗口改报 WINDOW_NOT_READY，不因此误报真实显示丢失；APP_TAKEN_OVER 控制权保护不移除。

交还巡检确认同一主屏窗口、边界及显示几何稳定至少 400ms，再释放旧屏；完成/保留页面清理同样保护进行中的移屏。正常完成仍停止采集，不新增常驻渲染、系统动画修改或强制重启 App。e2acd6f 基线的 CI/原签名包已实际核验，但不能据此保证 ColorOS 闪烁消失。

## 2D. C014 常用任务原生接入与提示词压缩

common_task 通过原生目录/权限过滤/运行时/隐私归档/工作过程展示接入；与任务页面共用原子文件。按需分页列出、单项读取、保存、编辑和删除，不要求开启 Root、终端或长期记忆。只保存不启动；用户要求执行已存任务时读取最新版，使用现有会话工具完成；页面执行和桌面捷径仍按既有逻辑开启新普通会话。

写入用内容 revision 防止覆盖并发修改；相同名称/正文的重复创建复用条目，不覆盖不同正文同名任务。StateFlow 刷新 UI，加载期间变化会合并刷新，无定时轮询。校验值不返回模型，角色会话只读，子智能体不修改库。快捷方式 SDK 返回 false 与实际保存结果分开报告。

压缩重复系统提示及 GUI 路由说明，保留用户提示、历史、记忆和既有安全规则。整库不自动注入，库改变不改系统前缀/工具 schema。固定全功能样本系统文字 8710→6707 字符；系统消息和基础工具 JSON 83128→77169 UTF-8 字节（约 −7.2%）。不是 token 或实际预填充耗时测量，服务商/缓存/历史仍影响等待。详见[源码说明](https://github.com/Lmin2419/eta-background/blob/6016745315267d1bb9525039757353b605527ab3/etax/COMMON_TASK_AGENT.md)。
