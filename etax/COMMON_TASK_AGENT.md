# 常用任务原生接入与提示词优化

2026-11-02，基于 `e2acd6fb5eec4c8459ff409afd302d321941afbe`。用户确认常用任务界面可用，但 Agent 不知道该能力，要求底层接入并减少预填充等待。此候选保留 e46 的点击、窗口和完成页面交还修复，未修改 Root 引擎或系统 Hook。

## 对话与任务页面共用一份流程

`common_task` 是本地原生工具，经模型目录、能力过滤、运行时路由、隐私归档与 UI 展示完整接入，不依赖 Root、无障碍、终端、MCP 或持久记忆开关。

| 操作 | 行为 |
| --- | --- |
| list | 按名称筛选，分页返回 ID、名称、revision；最多 20 条，不返回流程正文 |
| get | 根据 ID 读取一项完整流程；不自动执行 |
| save | 新建，或持 ID 和最新 revision 编辑；相同名称/正文的重复创建复用原条目，不覆盖不同正文的同名任务 |
| delete | 持 ID 和最新 revision 删除；旧 revision 不得删除用户刚更新的任务 |

用户说“保存为常用任务”只保存；要求“运行这个常用任务”时，Agent 读取最新版，在当前会话通过原有工具执行。任务页面和桌面快捷方式仍开启新普通会话，使用当前模型。没有新增任务调度、教学学习、跨会话执行器或自动定时。

提示词说明该能力及按需读取规则；不把所有名称/流程注入每次请求。编辑库不会改变系统前缀和工具 schema，也不额外请求模型总结。用户当前指令、权限与前后台选择规则仍优先；角色会话只读，子智能体不负责修改该库。

继续使用 `common_tasks.json` 版本 1 的原子文件与既有限额（64 条、名称 60 字、流程 8,000 字）。内容 revision 从 ID/名称/正文计算，不需要迁移旧文件，不包含快捷方式随机校验值。主 UI 和 Agent Runtime 当前在同一进程，共用写入锁；变更通过 StateFlow 通知已打开页面，加载期间的新变更会合并刷新。编辑窗口中的旧版本提交会被拒绝并提示重新打开最新流程。没有文件扫描或定时轮询。

快捷方式仍按本地 ID/校验值解析最新指令，Agent 修改会更新其标签，删除会禁用；Launcher 更新失败不撤销已经保存的数据，工具结果单独说明。原始工具参数/结果走敏感归档策略，工作过程只展示动作，不公开流程或校验值。损坏文件不会被清空覆盖。

## 预填充输入量

压缩内置系统提示中重复的执行、界面反馈、Android/Linux 分工、浏览器和子智能体说明；缩短反复附在原生 GUI 工具上的执行位置描述。没有按关键词临时删工具、改变工具参数/校验规则或覆盖用户提示。后台能力条件、观察/截图一致性、未知结果不重放、短提示/无进展保护、冻结禁令、用户接管与锁屏主屏保护保留。

对比使用实际 `AgentPromptBuilder.buildSystemMessages` 与 `AgentToolCatalog.build` 构造后的 JSON；Root 可用、默认设备工具、无历史/记忆/Skills/图片/自定义提示/执行上下文。全功能组开启终端、浏览器、子智能体提示；基础工具 schema 不包含运行时追加的子智能体等工具。这是固定输入样本，不代表每个真实请求。

| 样本 | 系统文字：改前 → 改后 | 系统消息 + 基础工具 JSON（UTF-8 字节） |
| --- | --- | --- |
| 终端/浏览器/子智能体提示关闭 | 5,631 → 4,669 | 52,415 → 48,837（减少 6.8%） |
| 三项提示开启 | 8,710 → 6,707 | 83,128 → 77,169（减少 7.2%） |

已经计入新增常用任务 schema 和说明。全功能样本的内置系统文字减少约 23%；不能把字符/字节下降写成 token、前缀缓存命中率或首字等待提速比例。实际等待仍取决于服务商、模型、历史、图片、网络和缓存策略。用户自定义提示、历史与记忆均未截断。前缀稳定性的已有 Root 检测规则继续保留。

## 验证与手机检查

自动化覆盖原生注册/运行时路由、无 Root/终端/记忆/无障碍时可用、不中断其他任务 GUI 所有权；读取/保存不启动任务；库与快捷方式身份保密、冲突保护、并发去重、分页、损坏文件、角色只读、已打开页面刷新与旧编辑拒绝；64 项长流程仍不改变提示前缀，输入预算回归，以及原有前后台路由/提示约束。完整检查与签名包结果以该候选的 CI 和协作记录为准，不沿用基线结果代替新 head 的验证。

手机可按以下短流程验证：

1. 新会话问“你能管理常用任务吗”；应说明内置能力，无需安装插件或打开终端。
2. 说“保存一个常用任务，叫计算测试：在后台打开计算器，计算 123×45，告诉我结果；现在只保存，不要执行”。常用任务页面应出现条目，计算器不启动。
3. 在对话中把它改成 200＋300；任务页面同步更新，旧桌面快捷方式执行新流程。再说“运行计算测试”，应实际执行后回答 500，不把保存成功当成执行成功。
4. 删除测试条目，页面与快捷方式不再执行它。不要为测试创建敏感或有外部副作用的流程。

比较等待时间请固定模型、网络和任务，区分第一次与缓存后的请求，并使用已有执行统计；这里没有虚构真机提速结果。e46 的最近任务过渡与点击改善仍须用户设备反馈，历史 LSP 软重启未列为已修复。
