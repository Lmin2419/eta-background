## 从截图发现并修正的问题

1. 卡片 border 设置覆盖了圆角：调整 modifier 顺序。
2. 文字型圆形按钮默认 padding 导致菜单和发送符号裁切：改用原生 Button 内的 SVG，显式设定尺寸和 padding。
3. 输入区的弹性布局导致发送按钮位置不对：为模型入口约束宽度，两端对齐。
4. Scroll 的短列表默认垂直居中：会话侧栏、模型列表和目录页显式顶部对齐。

这些修改已在当前源码中复查并重新截图。此前交付的 0.9.0 ZIP 保留原样；本轮截图不是旧 ZIP 的逐字节验收。截图包附当前组件源码摘要和修改文件副本，便于追溯。

## Linux Previewer 环境处理

API 26 `PreviewBuild` 编译 `FoundationPreview.ets`。该入口复用生产 `AssistantShell`、`ChatPage`、`ProviderPages`，仅存储和 API 使用内存替身，不在生产 `main_pages.json` 内。

SDK 原始 Linux 环境遇到缺失动态库别名、同名 EventRunner 符号 ABI 冲突、预览资产路径校验和页面模块路径不匹配。处理全部位于外部 `/workspace/preview-runtime/`：

- Xvfb + 软件渲染，补齐 `.z.so`、hilog、zlib 加载别名。
- LD_AUDIT 对渲染库内的冲突符号做局部绑定；此兼容文件含 SDK 版本相关偏移，不是通用 SDK 修复。
- bwrap 临时挂载符合运行时约束的资产路径，不改宿主系统目录。
- LD_PRELOAD 仅补全加载模块的 `entry/ets/` 前缀，不改 UI、业务状态或模型响应。
- 使用 Previewer 命令通道发送原生点击和 inspector 指令，从图片通道保存 JPEG。

SDK 文件、正式应用入口和 HAP 不包含这些兼容库。捕获脚本与兼容层源码保留在截图证据包的 `runtime/`，并已归档到仓库的 `scripts/preview-diagnostics/`；不是手机运行依赖。
