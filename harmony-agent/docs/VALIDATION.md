表单回调防护在单测验证的是实际使用的 core 函数；ArkUI 在目标机上的焦点、重建和输入行为仍要复测。UI 改为 ArkUI 卡片/底部导航、背景模糊开关、窗口安全区回读与键盘导航避让。编译通过不等于已在目标折叠屏取得视觉验收。

后台服务现在先检查通知权限，并回读系统任务 ID 后才显示已启动。实际授权、通知展示、原生通知按钮、系统取消回调与长时间运行尚未在用户手机验证；95 项通过不包括这些 OS 行为。任务通知控制入口只接受当前进程 nonce，旧通知不能控制后续任务。

虚拟屏已经读取用户连接仓库的 Root Android 实现，并核对 SDK 特殊权限。此次提供可在手机执行的权限/显示/HDC 帮助检测入口；未做虚拟屏创建/第三方 App 迁移/跨屏输入，不把能力查询计作后台屏执行成功。见 VIRTUAL_SCREEN.md。

升级包只含 entry/src/main 的代码/资源/清单与 AppScope/app.json5，不覆盖 build-profile.json5、签名资料或原生库。导出后在旧 0.3 工程上合并构建验证，不等于已签名真机覆盖安装。
