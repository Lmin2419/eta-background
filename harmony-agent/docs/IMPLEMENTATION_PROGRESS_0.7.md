## 相对 0.6 的实质进展

- 模型：分阶段诊断四项能力；目录元信息只标服务报告；安全过滤的附加请求头；可选推理/输出预算；来源明确的 Token 用量。四种协议各有流与工具完整性校验。
- 聊天：角色独立会话、修订来源、附件和滚动位置持久化、可查看的上下文裁剪记录、长代码复制、表格横向阅读、深色主题。任务不由页面生命周期持有。
- 扩展：Skills 资源导入/版本冲突/开关/卸载/导出；角色 JSON/PNG 与世界书；远程 MCP 逐工具开启、凭据隔离与取消；有限次数的次模型文本分析。
- 浏览器与语音：助手内 ArkWeb DOM/导航/输入/静态截图和地址标签；前台离线录音转写、限定 WAV 导入、播报暂停续播。关闭网页或离开助手后不继续占用相应操作入口。
- 系统：电量网络、主动选择联系人、系统日历编辑页、一次位置授权；应用目录使用用户维护的真实入口资料，未假定可枚举所有应用。
- 数据：模型/偏好迁移到 RDB；会话/配置/扩展/草稿/设置一起事务恢复，文件先校验暂存再切根目录；CRC 校验、路径/大小限制；Key 与运行授权不进入备份；旧恢复目录可手工清理。
- 稳定性：HDC/MCP/网页动作结果未知时停止，不把错误交回模型反复尝试；停止后迟到回调不能恢复执行；关闭记忆会结束使用旧缓存的任务；通知续聊可用当前进程临时 Key，重启后不恢复。
