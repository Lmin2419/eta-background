## 当前工作方向

**2026-10-30 更新**：用户决定界面与交互改为照 Eta 源码 1:1 移植，作为 ROADMAP 的 M1（E01–E09），规范见 [ETA_PORT](ETA_PORT.md)。下面是 0.9 时期的背景。
