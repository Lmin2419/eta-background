## 当前工作方向

**2026-10-30 更新**：用户决定界面与交互改为照 Eta 源码 1:1 移植，作为 ROADMAP 的 M1（E01–E09），规范见 [ETA_PORT](ETA_PORT.md)。下面是 0.9 时期的背景。

用户在 0.6–0.8 真机体验中反馈：模型测试 / 获取目录会重置表单，聊天和导航混乱，流式过程不可见，后台通知等功能不稳定。用户随后明确要求先保存旧源码，暂不保留全部入口，优先按自有 Eta 分支重建页面和交互框架。

因此，当前交付重点是聊天、会话、模型服务及页面导航。旧手机执行、通知、扩展等实现被保留，但不从新入口启动。历史 83 项功能表不作为 0.9 的上线完成率；当前仍不是上线版。

## 最近完成的布局修正

- 卡片边框设置覆盖圆角：调整 ArkUI modifier 顺序。

这些修正在当前源码中。此前交付的 0.9.0 ZIP 未覆盖，不能用其文件名推断它含有本轮改动。

| 旧能力 | 当前处理 |
| --- | --- |
| 本机 HDC、UI 树、截图、点击、应用调度 | 保留旧源码，未接入 0.9 页面；手机端授权与连接需重新验收 |
| 通知控制、短时后台、定位类型持续后台 | 保留旧实现与说明；未证明获得长期后台资格，当前正式入口不启动这些服务 |

## 后续执行顺序

1. 在目标真机检查首页、输入法、系统栏、横竖屏、折叠和字体缩放。
2. 配置用户真实 API，验证测试 / 获取目录 / 导入 / 保存不会清空表单；分别测试空 Key、非空 Key 和无 `/models` 的服务。
