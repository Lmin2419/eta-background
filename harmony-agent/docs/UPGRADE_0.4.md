# 从 0.3 升级到 0.4（保留你刚配置好的签名）

适用于已经用 0.3 DevEco 工程安装成功的手机。不要卸载手机上的助手。

1. 下载 `harmony-agent-0.4.0-upgrade.zip` 并解压。
2. 将其中的 `entry` 和 `AppScope` 文件夹复制到**原来已经签名成功的工程根目录**（能看到根目录 build-profile.json5 的位置）。Windows 提示时选择合并文件夹、替换同名文件；不要先删除原文件夹。
3. 升级包不含根目录/模块的 build-profile.json5，不改签名或预编译库。保留你已经配置好的 `signingConfigs` 和产品的 `signingConfig: default`。
4. 回 DevEco，执行“文件 → 同步和刷新项目”，再“构建 → 清理项目”，选择手机，点绿色 Run。
5. 仍使用同一个包名和签名覆盖安装，启动后“设备”页底部应显示 `随身助手 0.4`。首次系统若再次请求权限，按你的选择授权。

默认包名仍为 com.example.harmonyagent。如果你自己修改过包名，合并前保留 AppScope/app.json5 中你自己的 bundleName，仅将 versionCode 更新为 40000、versionName 为 0.4.0。包名或签名不同不能作为原应用直接升级。

## 这版优先验收

- 模型页填名称、地址、Key、模型 ID 后，连续获取模型/测试连接，分别验证成功、401、断网；输入不应清空。你的 HTTP 服务需要打开地址下方的“允许此 HTTP 服务”。
- 来回切换聊天/模型/设备页面；模型草稿保留，设备读取结果只显示在设备页，连接状态不因同值回调被清除。
- 模型页与设备页顶端对齐，系统状态栏和手势区背景连续；折叠/展开、旋转、弹出键盘检查底部输入与导航。
- “设备 → 启动后台服务”，检查授权提示与状态；系统确认后下拉通知栏核对定位任务通知。若没有，点“检查系统状态”，复制状态和错误码。
- 运行一个无敏感数据的手机任务，下拉通知栏检查任务进度、“返回助手”“停止任务”；结束后同一任务卡更新结果。系统是否展示横幅由其通知设置决定。
- 单轮结束后，手动启动的后台服务应保留；删除系统定位任务通知或点击停止服务应结束服务和借用它的手机任务。重启助手不自动恢复后台服务。
- “虚拟屏能力检测”只收集接口/权限信息；此版不提供后台虚拟屏执行。

自动化测试与 HAP 编译不替代以上真机触控、通知和权限验收。
