## 升级与基础体验（全部待真机）

1. **PHONE-01** 同签名覆盖 0.5/0.6：原会话与模型目录保留；载入失败不清空历史；退出后再次打开仍可读。
2. **PHONE-02** 外屏、展开、横屏、键盘、系统大字体、深色/浅色：消息能滚动，停止按钮可点，输入框与底部导航不重叠。比较本会话原始问题截图，不能只看首页。
3. **PHONE-03** 表单填写后依次获取模型、测试连接、服务返回错误、取消诊断、切服务：当前输入与 Key 不应被旧请求覆盖。目录分页去重、多选、取消和手填均核验。
4. **PHONE-04** 四项诊断分别观察文本、流、工具、合成图片状态；工具诊断不能操作手机。每个真实服务单独测试，不能由一个服务推断其他服务可用。
5. **PHONE-05** 长回复上滑后继续生成不能拉回；切换会话、杀进程、重开后草稿/附件/浏览位置恢复。停止保留部分文字，不能标成已完成。
6. **PHONE-06** 编辑重发保留旧轮次与执行记录；新运行显示修订来源。上下文达到预算时保留当前目标和完整工具对，超过不可裁剪预算应停止而非继续猜测。

## 任务、通知与设备（全部待真机）

7. **PHONE-07** 两个聊天会话并行、同会话排队、一个主屏任务互斥。共 8 个未结束任务后明确拒绝；停止后队列保留并等待继续。插话等旧任务收尾后再启动。
8. **PHONE-08** 通知授权与拒绝：运行卡两按钮分别控制准确任务；点击本体进入准确会话。完成卡显示结果摘要；打开 App 仅显示观察确认过的目标。
9. **PHONE-09** 删除运行/完成通知后，再有进度、终态、重启均不得复活。保留最多 3 张完成卡。旧卡不能控制新任务。
10. **PHONE-10** 完成提醒开/关、息屏完成、解锁、重复回调：不会补播或多次提醒。内联输入是可关闭的实验；四种进程/锁屏组合记录是否真正投递。
11. **PHONE-11** 息屏暂停、亮屏不自动执行、回助手暂停。继续后必须新观察；折叠/旋转使旧坐标失效。
12. **PHONE-12** 本机 HDC：断开电脑后读页面、长按、拖动、中文输入、等待条件；不同命令必须以设备 help/执行证据确认。断连/无结束标记停止，不重试未知动作。
13. **PHONE-13** 后台实际资格、系统回读与取消：记录请求时间、批准/拒绝、通知、切后台后的网络/HDC、撤销后的任务结果。进行 30–60 分钟及 100 次关键控制/折叠循环；观察内存/句柄，不以一次存活推断长期稳定。
14. **PHONE-14** 自动化场景先做无害流程：打开设置查看显示项、不修改选项；跨页面回退；滚动多个容器时拒绝歧义；三次无变化后第四次不再操作。闹钟/便签等需另录真实闭环，当前未验证。

## 扩展与数据（全部待真实平台/服务）

15. **EXT-01** 导入图片/文本、预览、取消、导出、精确编辑、多匹配拒绝、超限拒绝；不应访问其他应用私有文件。手工改写与运行中的工作区工具互斥。
16. **EXT-02** 开关长期记忆、查看/编辑/清空；切角色创建独立会话。关闭记忆应结束使用旧记忆上下文的运行，不再注入缓存。
17. **EXT-03** 导入 `docs/examples/research.skill.json`，启用、读取模板、升级冲突、卸载。越界资源拒绝，脚本不能执行。角色 JSON/PNG 往返与世界书触发条件分别测试。
18. **EXT-04** 远程 MCP：连接、只勾选一个工具、关闭服务、改地址清 Key、断连、超时、取消。工具未知结果停止；不能自动重发写操作。对自建测试服务先使用无害工具。
19. **EXT-05** 次模型：只得到独立子问题，无主屏/文件工具；最多 4 次；主任务取消传播。未保存 Key 的配置在当前进程可用，重启后须重新填写。
20. **EXT-06** SearXNG 搜索、HTTPS 抓取、引用来源与错误。助手内浏览器导航、地址标签、DOM、截图、填表；手动触摸使旧观察失效；收起浏览器后工具不能继续操作。
21. **EXT-07** 麦克风拒绝、开始/结束/取消、切后台停止、WAV 转写、TTS 暂停续播。离线资源缺失给出错误，不自动开后台录音。
22. **EXT-08** 系统工具默认关闭；打开后测试电量网络、用户选择联系人、日历编辑取消/保存、一次位置权限拒绝/授权。不得读取整本通讯录或全量私人日历。
23. **DATA-01** 备份恢复：先导出；校验损坏 JSON、重复文件、CRC 错误、超限文件均不覆写。恢复后会话/角色/技能/文件/草稿一致，模型和 MCP Key 必须重新填写，旧运行不复活。
24. **DATA-02** 存储写失败、进程在迁移/恢复中退出：原文件或事务前状态可恢复；不得继续执行新的副作用。平台 RDB 故障注入本环境未能执行。
