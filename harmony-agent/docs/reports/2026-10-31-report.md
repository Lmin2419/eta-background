## 阻塞与原因

1. **E07b 是数据模型决定，不是 CI 失败。** 固定 Eta 原测试要求 60 会话、完整大正文和 history/journal、角色修订、数据库分页与增量事务；现有 0.9 是有 50 会话、消息长度及全库大小限制的轮次 JSON 快照。仅改 UI 窗口或缩短测试样本不能通过原始验收。依据用户“会影响后续的决定则保留草稿”规则，#22 记录了差异、17 项原测试账本和具体迁移方案，未切换用户数据。
2. **E05 仍欠执行偏好。** 默认思考、自动压缩是最终 A 类目标；当前明确禁用，未把无效开关伪装为已实现。E08 页面入口也尚未接入。不能把设置页渲染完成当成这些能力完成。
3. **E06 仍有对齐缺口。** 内置服务种子/恢复内置服务未补齐，完整模型能力覆盖和部分标签未接；自定义请求头 ASSET JSON 上限 1KB；少量新增补充提示存在中文回退。主要编辑和导入路径可审查，完整 1:1 仍待补齐与真机核对。
4. **真实编译与视觉验收缺席。** 本环境使用公开 SDK 做官方 ArkTS 和 restool 检查，未生成 HAP。没有将自动检查、数据投影或逻辑模拟截图冒充鸿蒙真机结果；继续保留实色降级与原生组件选择。
5. **E08 条件未满足。** 已按顺序完成可独立交付的 E05/E06，不继续扩大到记忆、Skills、MCP，避免把存储和页面未完成项掩盖在更多新入口里。
