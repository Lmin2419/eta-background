## ⑥ 无障碍扩展实验（D0a）

目的是回答三个问题：
1. 普通应用的无障碍服务能不能在系统设置里开启；
2. 能不能读到其他应用的控件；
3. 能不能注入手势。

> 预期：公开 SDK 里这一整套接口自 API 12 起都已弃用，而且没有公开的替代接口，所以**很可能不可用**。不可用也是有价值的结论，请照实记录。

| # | 操作 | 需要记录 |
| --- | --- | --- |
| ⑥-1 | 系统设置 → 辅助功能（或“无障碍”）→ 已下载的服务 / 更多服务 | 有没有“随身助手”；能不能打开开关 |
| ⑥-2 | 打开开关 | 所有系统弹窗的**原文**（授权提示、风险提示都算） |
| ⑥-3 | 回到随身助手：设置 → 诊断 → “无障碍实验” → 点“刷新” | 连接状态是否为“已连接”；前台包名；控件数是否大于 0；最近事件时间是不是 `-`；有没有“读取错误” |
| ⑥-4 | 切到别的应用（例如“备忘录”），几秒后切回来，点“刷新” | 前台包名是否变成刚才那个应用；控件数是否变化 |
| ⑥-5 | 点“请求注入点击”，等 1–2 秒，再点“刷新” | 注入结果（`ok`、`not-found` 或 `error:…`），以及“点击次数”是否**真的**加一 |
| ⑥-6 | 直接点“无障碍注入测试按钮” | 点击次数加一，确认按钮本身可用 |

“点击次数”只会在按钮真的被点到时增加。注入结果是 `ok` 但次数没变，说明系统接受了手势、但没有点到按钮，请照实记录。
