# 检查点 B：真机统一验收

本轮（第四轮）所有 PR 合并到 `harmony/ui-preview-tests` 后，用户一次装机验完。下面每一项都写清楚“怎么做”和“看到什么算通过”。

## ⑥ D0a 无障碍扩展实验（0.9.36）

目标：回答三个问题——普通应用的辅助功能能不能在系统设置里开启、能不能读到别的应用的控件、能不能注入手势。

| # | 操作 | 预期 / 要记录 |
| --- | --- | --- |
| 1 | 系统设置 → 辅助功能（或“无障碍”）→ 已下载的服务 / 更多服务 | 记录服务显示的名字（应为“随身助手”）；能不能点开、能不能打开开关 |
| 2 | 打开开关后回到“随身助手” | 记录系统弹窗的**原文**（授权提示、风险提示都算） |
| 3 | 打开“设置 → 诊断”，找到“无障碍实验”区，点“刷新” | 连接状态应为“已连接”；前台包名应为 `com.huawei.hmos.settings`（或系统设置的实际包名）；控件数 > 0；最近事件时间不是 `-` |
| 4 | 切到别的应用（例如“备忘录”）再回到“随身助手”，点“刷新” | 前台包名变成刚才那个应用的包名；控件数随之变化 |
| 5 | 在“无障碍实验”区点“请求注入点击”，等待 1–2 秒后点“刷新” | 注入结果应为 `ok`；“点击次数”加一 |
| 6 | 直接点“无障碍注入测试按钮” | 点击次数加一（确认按钮本身可用） |

需要记录：服务在设置里的名字、能否打开、第 3/4 步的包名与控件数、第 5 步注入结果与计数、所有系统弹窗原文。
