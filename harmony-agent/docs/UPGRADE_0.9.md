# 0.9 框架预览：保留签名升级

这版有意缩小范围，只核验聊天、会话与模型服务的新框架。旧通知、手机执行等入口暂时撤下。

1. 复制电脑上整个旧工程文件夹作为自己的备份；不要卸载手机上的旧 App。
2. 关闭正在运行的构建，解压 `harmony-agent-0.9.0-upgrade.zip`。
3. 把压缩包内的 `AppScope` 和 `entry` 两个文件夹合并到原工程根目录，出现同名文件时覆盖。不要覆盖或删除你原有的根目录、entry 下的 `build-profile.json5`。
4. 用 DevEco 打开原工程，“文件 → 同步和刷新项目”；再“构建 → 清理项目”。确认工具栏模块是 `entry`，目标是自己的手机。
5. 点击 Run。沿用同一个包名和签名，正常情况会覆盖安装并保留数据。若提示签名不一致，停止安装流程，检查是否打开了新解压工程或换了签名；不需要通过卸载来解决。
6. 应用右上角菜单 → 设置应显示 `0.9.0 · 交互框架预览`。首页没有旧的三栏导航和设备页面。
7. 从“模型服务”打开旧配置。测试连接不应清空名称、地址、Key 或默认模型。目录获取后可搜索、多选，点“添加所选”，最后“保存服务”。
8. 返回首页，在输入区选择模型，发送一句普通问题。确认消息可读、回复逐段出现、停止按钮有效；再切换会话确认各自输入和模型。

旧版本未安全保存的 Key 只存在旧进程内存里，覆盖安装重启后可能需要重新填写；这不等于配置被清空。模型与聊天草稿使用同一数据库格式。本版只显示旧对话的用户/助手正文，旧工具步骤和扩展配置暂不提供入口，也不会自动重放。

## 完整工程安装

没有可用旧工程时，解压 `harmony-agent-0.9.0-deveco.zip`，用 DevEco 打开里面的 `harmony-agent` 文件夹。安装 API 26 SDK；在项目结构的签名配置中登录自己的华为账号，生成 `default` 调试签名。

工程的 `app.products[].signingConfig` 已关联 `default`，证书必须由你自己生成。不要把别人的签名配置覆盖进去。HAP 为未签名构建产物，不能直接点文件安装。

## 电脑端预览

打开 `entry/src/main/ets/pages/FoundationPreview.ets`，在 DevEco 的 Previewer 面板刷新并开启交互。页面使用明确标记为“示例”的内存模型配置；所有操作都是预览数据，关闭后丢弃。聊天、侧栏、服务详情和弹层与正式页面共用组件。

预览能检查布局和交互，但系统安全区、键盘、软硬折叠切换、网络权限、ASSET 密钥存取以及覆盖安装必须在真机上另外核验。当前云端 Linux 原生预览已取得 15 张截图和实际点击记录，使用模拟 API；详见 `VISUAL_VALIDATION_0.9.md`。
