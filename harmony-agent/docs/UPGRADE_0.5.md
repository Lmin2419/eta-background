# 升级到 0.5：保留原签名与手机数据

适用于已经安装 0.3 / 0.4 的手机。不要卸载助手。

1. 解压 `harmony-agent-0.5.0-upgrade.zip`。
2. 将 `entry`、`AppScope` 合并到原来签名成功的工程根目录；选择替换同名文件，不先删除原文件夹。
3. 回到 DevEco：文件 → 同步和刷新项目；构建 → 清理项目；选择手机，点绿色 Run。
4. 打开设备页，底部应显示“随身助手 0.5”。原模型配置、密钥和聊天数据继续使用。

升级包不包含根目录或模块的 build-profile.json5、证书、预编译库，所以保留你的签名设置。若你曾修改包名，请保留自己 AppScope/app.json5 中的 bundleName，仅更新 versionCode 为 50000、versionName 为 0.5.0。同一包名、同一签名覆盖安装才保留原数据。

## 这版怎样使用

- **模型**：选择旧服务或新建，填写地址、Key。点“连接并获取模型”，在面板搜索、勾选或全选模型，点“添加”，最后“保存服务”。以后在聊天输入框底部切换服务和模型。获取失败保留已有目录和输入。
- **测试**：“测试并刷新目录”在已有模型 ID 时检查模型与工具调用，再拉取目录；没填模型 ID 时先连目录，不要求猜模型名。服务不提供 /models 时仍可手填 ID。
- **流式**：默认开启。发送后边生成边显示；不支持流式的服务，可在模型页关闭后保存。不会因失败自动重发。服务若自行缓冲或只返回完整 JSON，收到内容前仍需等待。
- **聊天**：顶部会话标题、消息列表、底部紧凑输入区；底部导航不再盖住顶栏。展开屏幕时优先保留消息空间，足够宽时显示侧栏。消息支持段落、标题、加粗、列表、引用和代码块。
- **执行**：从输入框下方选择“操作手机”；任务步骤可展开，停止按钮与输入框并排。任务期间可先写下一条，但不会自动发送。读较早消息时不强制跟随输出，点“↓ 最新消息”回到底部。
- **停止/断网**：已收到的部分文字保留并标明未完成；不会把不完整工具调用执行掉。每个模型回合结束、用户停止或请求失败时保存当前文字，若进程被系统直接杀掉，当前尚未保存的回合片段可能丢失。
- **设备连接**：调试会话失效会清除“已连接”，能力检测停止后续命令；重新读取手机无线调试地址并点“连接本机”。不会重复未知结果的点击。

## 虚拟屏是独立实验

普通升级包不申请 ACCESS_VIRTUAL_SCREEN，避免未经 ACL 授权导致安装失败。另见随包“虚拟屏实验说明.txt”。只有合法调试 Profile 实际授权后，“实测创建与释放”才会创建一个不抢焦点的小屏幕并立即释放。创建成功仍不等于第三方 App、截图和输入可在后台屏运行。

## 建议这次确认

1. 折叠/展开、横竖屏、键盘开合后，消息可以连续阅读，导航位于底部，输入区不挡内容。
2. 旧服务获取目录 → 搜索多选 → 保存 → 重启 → 聊天切换模型；测试、401、断网均不清空表单。
3. 让模型写一段较长文字，确认边收边显示；上滑看历史不被拉回，停止后部分回复仍在。
4. 手机任务的工具步骤、暂停、停止和任务通知；系统定位通知的存在仍需设备页“检查系统状态”及通知栏核对。

云端已做核心自动化测试和 SDK 编译；以上真机显示、键盘、网络流事件、系统权限和通知行为尚未直接验证。
