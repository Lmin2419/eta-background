# 0.8 验收开发版升级

0.8 在 0.7 上补齐运行配置失效、数据维护互斥和常用任务模板，仍未通过真机发布闸门。不要卸载旧版后安装。

1. 复制原 DevEco 工程作为备份；旧应用里导出重要会话。0.6 已有的“升级包”不是数据备份。
2. 解压 `harmony-agent-0.8.0-upgrade.zip` 到原工程根目录，覆盖同名文件。根签名配置、证书、原生库配置不在覆盖范围。升级包内 AppScope/app.json5 使用既有默认包名 com.example.harmonyagent；若你曾改过包名，请保留原文件，仅把 versionCode 改为 80000、versionName 改为 0.8.0。
3. 使用原签名，同步工程后点击 Run。构建 SDK 使用 API 26。原生库未变，升级包不要求 Windows 重新编译 C++。
4. 启动后旧 JSON 会话、模型元数据和偏好会按需迁移到 RDB；旧 JSON/偏好文件保留。遇到载入失败不要卸载，保留原文件和错误记录。
5. 打开“设置 → 扩展与数据 → 备份恢复”，先导出一份备份。备份包括会话、模型元数据、草稿、偏好、角色、技能、MCP 配置及工作区文件；不含模型/MCP Key、HDC 密钥、后台运行授权。
6. 运行中的旧任务不会在重启后自动恢复点击。请重新连接本机调试并观察当前页面。
7. 按 `ACCEPTANCE_0.8.md` 执行真机核验，记录失败项编号、错误文本和截图。无需重新安装或反复修改签名来处理普通功能问题。

## 0.8 新增

聊天输入栏新增“模板”：查看页面、一次闹钟、新建便签。可以填写桌面应用名称，无需先查包名；已有入口则可从目录选择。模板先预览再填入，最后点发送才会执行。应用目录支持 JSON 导入和导出，导入的“曾验证”标记会清空。

工具、MCP、技能或角色的执行配置改变后，旧任务会停止；未发送的队列会按执行时的新配置准备。数据保存或文件选择进行中，备份/恢复提示稍后再试。

## 主要入口

- 聊天：任务、排队/插话/补充、附件、语音、网页；回复下方有播报、暂停、续播、编辑重发和重新生成。
- 模型：四类协议、目录获取/多选、四项诊断、输出预算、推理参数、非密钥附加请求头。设置页上下文预算是保守字符估算，不是精确 tokenizer。
- 设置：文件/记忆/搜索/系统工具；扩展页管理 Skills、角色、MCP、次模型、常用应用与备份；能力报告可导出。

## 有意保留的边界

- 浏览器仅控制助手自己的 Web 视图，切换地址标签会重新导航；没有外部浏览器接管。静态网页截图不保证视频画面。
- 语音使用系统离线引擎；音频文件仅支持 PCM16、16kHz、单声道 WAV，最长约一分钟。续播从暂停的段落重新开始。
- 角色 PNG 导出携带角色数据，使用一像素封面；不会保留导入卡片的插画。
- Skill 使用文本 JSON 资源包；不在手机执行脚本。仓库提供打包脚本和导入示例。
- MCP 支持 Streamable HTTP 工具调用和 Bearer 凭据；不提供 OAuth 登录、旧 SSE 双端点或 stdio。超时/断连不自动重放工具。
- 长期后台定位方式仍属原有实验，默认关闭；不能把普通任务通知当作保活。虚拟屏、电源键、LiveView 等没有标为普通用户可用。
