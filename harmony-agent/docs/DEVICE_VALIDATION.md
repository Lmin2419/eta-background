# Pura X Max / HarmonyOS 7 真机验证

除下面已记录的 0.3 用户反馈外，本文件项目均为**待测**，不要把“代码已实现”填写成“手机已验证”。不需要把签名私钥、模型 Key、私人页面截图发到仓库。

| 步骤 | 操作 | 通过标准 |
| --- | --- | --- |
| 系统信息 | 记录完整 HarmonyOS 版本、API 版本、机型 | 明确具体系统构建，而非仅“OS 7” |
| 初次安装 | DevEco 调试签名后安装启动 | 应用正常显示，原生库无加载错误 |
| 手机独立连接 | 拔掉电脑连接；开启无线调试，输入地址端口，连接并授权 | 助手显示实际 shell/UITest 探测成功 |
| 页面读取 | 不填 API Key，点“测试页面读取” | 控件数非零，分辨率符合当前屏幕，截图成功 |
| 内外屏切换 | 折叠/展开后分别测试页面读取 | 尺寸更新；旧观察不能继续执行动作 |
| 模型配置 | 新建两个不同服务的配置，分别保存 Key、切换、重启应用、删除其中一个 | 密钥与服务正确配对，另一个配置不受影响，关闭安全保存后重启不恢复 Key |
| 模型诊断 | 不连接 HDC，获取模型列表与测试连接；再手填不支持列表的服务 | 能单独测试；文本可用与工具调用通过分别提示，不执行手机操作 |
| 地址/HTTP | 修改 API 地址、尝试 HTTP、重定向及 401 服务 | 地址变更清空表单 Key；HTTP 仅明确开启后使用；重定向不跟随；错误不回显 Key |
| 普通聊天 | 不连接 HDC，关闭“操作手机”，连续两轮询问需要前文的问题 | 可以对话，不申请定位、不操作设备；第二轮理解同会话前文 |
| 会话切换 | 新建两个不同主题、不同模型配置的会话，切换并重启应用 | 对话彼此隔离，恢复对应模型；已删除模型提示重选 |
| 会话管理 | 搜索较早消息、重命名、加载更早记录、删除一个会话 | 搜索覆盖完整历史，其他会话不受删除影响 |
| 导出 | “更多 → 导出 Markdown”，选择保存位置，再尝试取消 | 成功文件含完整对话与步骤摘要；取消不报成功，不包含原始截图/参数 |
| 异常退出 | 在模型等待/动作执行期间结束助手进程，再手动打开 | 历史标为中断，不自动连接/执行；正在执行的单步结果可能未知 |
| 窄屏/宽屏/键盘 | 折叠/展开、旋转、调大字体，打开键盘输入长消息 | 列表与聊天布局可用，发送/停止始终可触达 |
| 统一唤起入口 | 从有权启动应用的外部入口发起 harmonyagent://assistant，分别测试冷/热启动 | 打开聊天；正在 GUI 执行时请求暂停；没有自动提交、录音或接受外部工具参数 |
| 电源键候选 | 按 POWER_KEY.md 先做只读诊断 | 不将命令存在/目录可读当作绑定成功；当前版本未接管电源键 |
| 模型通信 | 配置支持 tools 的模型，先让它仅观察 | 输出与实际页面一致，未执行多余动作 |
| 跨应用 | “回到桌面，找到设置图标，但不要点击” | 无电脑参与，在后台完成并报告真实结果 |
| 点击验证 | “打开设置，找到显示设置，不修改任何选项” | 点击后根据新页面继续，而非只声称成功 |
| 文字输入 | 在无账号/无敏感数据的搜索框输入中文与引号 | 文字准确，命令符号不被 shell 解释 |
| 用户接管 | 任务中返回助手 | 显示暂停，新操作停止；继续后重新观察 |
| 停止 | 模型请求中、页面读取中分别点停止 | 晚到响应不再发起新的操作；已发出的单次动作可能完成 |
| 断连 | 任务中关闭无线调试 | 显示错误或停止，不重放未知结果的操作 |
| 超时 | 等待系统短时后台额度耗尽 | 任务停止，不显示虚假的常驻状态 |
| 持续模式授权 | 开启实验模式、开始任务，拒绝一次大致位置授权，再手动重试并允许 | 拒绝时不执行任务；允许后出现系统定位任务通知 |
| 通知取消 | 持续模式运行中删除系统定位任务通知 | Agent 停止，定位订阅释放，不重新挂通知 |
| 通知返回 | 点击持续任务通知 | 返回助手并暂停，用户可继续或停止 |
| 定位撤销 | 分别关闭定位总开关、撤销应用大致位置权限 | 停止 Agent；权限轮询路径在进程存活时最多约 3 秒检查一次 |
| 启动中停止 | 授权弹窗等待中停止任务，之后再允许授权 | 晚到的授权不启动 Agent、不残留定位订阅 |
| 持续运行与功耗 | 使用低风险长任务或暂停状态观察后台留存与耗电 | 记录实际时长和功耗，不能仅凭通知出现认定永久保活 |
| 再次启动 | 重启手机、重启助手，重新连接 | 需要时重新开启/授权调试；不假定授权永久有效 |

若“连接本机”失败，先区分：原生服务启动、TCP 地址/端口、系统授权、HDC 协议兼容、UITest 可用性。轻启已授权的身份不能直接当作本助手已授权。

若命令执行失败，记录助手的错误文本、发生前的普通页面、系统版本，以及是否在后台/折叠状态。模型无法修复调试权限或系统命令缺失，此时应先修执行器。

用户提供的轻启通知照片证明存在“正在运行定位任务，删除通知后任务将停止”的系统提示，但并不能单独证明轻启的采样频率、定位精度或内部实现。本助手的低功耗订阅属于独立实现，不声称完整复现轻启。
