## 与 Eta 的差异、待用户确认

- 使用已批准的原生菜单、弹窗、Slider、系统 Navigation。Slider 有整数步进，未复制 Miuix 磁吸曲线；截图检查点 ③ 后决定是否自绘。
- 按 SDK，切回“跟随系统语言”需冷启动；页面明确提示。未新增语言权限。
- 渐进模糊是 E02 的公开 API 尝试，未在设备截图验证。主聊天页暂不宣称已有 Eta 下穿模糊；当前接入 Scaffold 类页面与 Gallery。
- 默认思考、自动压缩仍是尚未接入的 A 目标，不能把设置页面交付写成这些执行能力已完成；E08 目标行也暂不启用。建议后续把这两项随执行偏好任务补齐，而非使开关仅保存外观状态。
- 反馈指向鸿蒙项目，版本不是 Android Eta 的版本。关于保留原作者及 Required Notice。
- 读取损坏偏好先用默认值显示，直到用户主动编辑才覆盖；存储/平台失败保留可重试路径。系统接口调用效果必须由真机确认。

## 新接口与权限

新增公开接口：`ApplicationContext.setColorMode/setLanguage`、`WindowStage.setCustomDensity`（API 20，目标 API 26）、`i18n.System.setAppPreferredLanguage/getAppPreferredLanguage`、`preferences.getPreferences/get/put/flush`；复用窗口系统栏、display、CustomDialogController、Slider、剪贴板接口。**新增权限无**；继承用户批准的 VIBRATE。signingConfigs 保持空。
