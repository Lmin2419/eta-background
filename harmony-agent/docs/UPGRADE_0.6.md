# 0.6 开发版升级

这是实施方案的阶段性开发版，尚未完成 83 项任务和整套真机验收，不能作为完整稳定版。

1. 先复制原 DevEco 工程作为备份；在原应用中导出重要会话。不要卸载旧应用。
2. 将 upgrade.zip 内容覆盖到原工程根目录。它只更新应用代码、资源、版本与模块清单，不覆盖根 build-profile.json5、签名证书或原生库配置。
3. 使用与旧版完全相同的包名及签名，在 DevEco 同步后点击 Run。
4. 首次启动把旧 conversations.json 验证后迁移到 RDB；旧文件保留。迁移失败应停止载入并保留原数据，不要通过卸载处理。
5. 此版新增任务记录、独立会话运行、任务通知、协议选择、附件和工作区。重启后旧运行显示中断，不自动补执行动作。
6. 新协议先使用“测试并刷新目录”验证你的服务；所有协议需真实服务复测。协议的根地址示例：OpenAI/Anthropic 为 /v1，Gemini 为 /v1beta。
7. “设置 → 文件与工具”管理沙箱文件和记忆；“聊天 → ＋附件”选择图片或文本。附件列表目前在进程内按会话隔离，尚未实现重启恢复。
8. 通知授权在设置页；通知继续对话默认打开对应会话。内联回复、锁屏投递、持续后台和虚拟屏仍待真机/资格验证。

不要将本版的普通通知理解为系统保活。关闭调试不能继续 GUI 执行；未知操作结果不会自动重试。
